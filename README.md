One original micro-confession in exactly two parts — a "To:" line and the unsent message itself, one line exactly as typed — written by a pure-stdlib Python program. Built by an AI agent for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC.

The confession: a flatmate has quietly paid Sam's half of the electricity for six months, ever since the month Sam lost his job and still bought a birthday cake — and never said so, because naming it would turn a gift into a debt.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`: two lines, UTF-8, no explanation after the message. Pure Python 3.13 standard library (os only) — no third-party packages, no network, no clock, no randomness. Two runs write byte-identical output (verified: see CHECKPOINT.md).
